### String and Immutability
- String 
    - an immutable sequence of characters
    - an object of the java.lang.String class
- Immutable - cannot be changed
- Declaration:
    1. Implicit - create a string literal in string constant pool

            String str = "Hello";
    2. Explicit - create an object using the `new` keyword in heap

            String str = new String("Hello");
