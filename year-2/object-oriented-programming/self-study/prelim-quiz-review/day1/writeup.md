## Concepts
- Programming - the act or job of creating programs
- Program - a set of ordered instructions ran by a computer
- Source Code - the raw instructions of the program itself
- Types of Programming Languages
    1. Compiled Language - the source code is translated into machine readable language before execution
    2. Interpreted Language - the source code is getting translated and executed, by an interpreter, line-by-line
    3. Bytecode Language - the source code is compiled into an intermediate form called bytecode and ran by a virtual machine
- Bytecode - a source code form readable by an interpreter and ran by virtual machines
- Java - a programming language used for creating embedded and mobile applications, web-based contents, enterprise software, games, and many more worldwide
- Java Technology Products
    - Java SE (Standard Edition) - used for creating applications ran on desktop computers
    - Java EE (Enterprise Edition) - used for creating large enterprise, server-side, and client-side applications
    - Java ME (Micro Edition) - used for creating applications on limited-power/limited-storage applications
    - Java Card - used for applications on smart cards
- Java Timeline
    - Green Team under the leadership of James Gosling created Oak as a solution for creating small devices such as television and cassette tape recorder
    - Oak was renamed as Java
    - In 1995, Netscape incorporated it to their browser
    - Oracle acquired Sun Microsystems in 2010
- Duke - Java's mascot created by Green Team's graphic artist, Joe Palrang
- Platform Dependent Programs
    - Workflow: 
        1. Source code is written
        2. Source code is translated into a platform-specific machine code
        3. Machine code is processed by a linker using a platform-specific library to turn it into a platform-specific executable
        4. Executable is ran by a platform-specific workstation
- Platform Independent Programs (Java)
    - Workflow:
        1. Java source code is written
        2. Source code is processed by a Java Compiler into a bytecode
        3. Bytecode is processed by a JRE on a workstation of any platform
        4. Bytecode is ran by a JVM
- Java Virtual Machine (JVM) - a dedicated VM for java that runs bytecodes
- Java Runtime Environment (JRE) - JVM with class libraries to run source codes
- Java Development Kit (JDK) - JRE with a compiler and other tools to build applications
- Integrated Development Environment - provides a sophisticated environment for programmers to write, debug, and run their source codes
